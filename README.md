# sfn-efir

SFN Helper — помощник эфира для San Fierro News (Evolve Role Play).

## Установка
1. Скачай архив: [Releases](https://github.com/Wereskkk/sfn-efir/releases/latest)
2. Распакуй всё в папку `moonloader`.
3. Запусти игру.
4. Активируй ключ: через окно или `/efirkey <ключ>`

Скрипт обновляется автоматически.
